v0.2.0

So many more file types We have added/changed

  • .mif loading/saving improved (and incompatible) from the MICA-GM version
  • .png loading - now when you finish your masterpiece of MS-Paint quality artwork you can load it back
  • Colour is now a 0-255 u8 instead of a 0-1 f32
  • we support (but do NOT recomend using) duckdood's .ST file format github page for duckdood's ST read/writer

how to run x86_64 (debian) extract mica.tar.gz and run the executable in the resulting folder

Bugs

  • inputting an empty save file path will cause MICA to crash
  • inputting an incorrect save file path will cause MICA to crash
  • inputting an empty load file path will cause MICA to crash except on .pngs
  • inputting an incorrect load file path will cause MICA to crash except on .pngs
  • inputting a non-numerical draw size causes a crash (somehow decimal resolutions work, don't ask how)
  • big brush sizes 130+ randomly try to draw outside the canvas and causes a crash
