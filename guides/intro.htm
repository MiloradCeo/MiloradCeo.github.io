Part 1 - What is Mica?



Mica is an art program made by Milorad, M.I.C.A. stands for Milorad Image Creation Application the use of the names Mica and M.I.C.A. are interchangeable

UI walkthrough


this is the main menu for Mica and is the first thing you'll see when you open the amazing Mica image editor/creator you can press Image editor to open the image editor/creator it will prompt you to enter the x size and then the y size and greets you with the image editor, we will get to that later though

you can press the Credits button to open the software credits

and the By using this software you agree to the terms of this liscense shows you the GPLv3 liscese that the software is under

once you press the Image editor button you will be taken to an x size selector where you can input a horizonal size or leave it blank to just use the avalable area of the screen as the canvas if you leave it black and press OK button you will be taken directly to the canvas, if you inputted a width it will then prompt you to enter a height (Y), once you press OK you will be taken to the image editor screen.
